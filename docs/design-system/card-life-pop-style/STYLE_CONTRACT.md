# 卡片生活誌亮藍風格契約

- 版本：v1
- 生效範圍：公開網站的視覺與互動呈現
- 變更規則：除非使用者明確提出「修改風格契約」，否則實作者只能在此契約內新增內容，不能自行改造風格。

## 1. 設計意圖

這不是傳統金融比較站，也不是復古雜誌。它是將複雜優惠轉成生活任務入口的明亮數位工具：

- 感受：清楚、活潑、可靠、有一點可愛，但不幼稚。
- 內容優先：每個高彩度區塊都必須是一個可用入口或資訊層級，不能只當裝飾。
- 閱讀節奏：大片白底與充足留白，搭配少量亮藍、萊姆綠、粉紅與黃色區塊。

## 2. 不可變的設計 token

| 用途 | Token | 值 |
| --- | --- | --- |
| 主要文字 | `ink` | `#151515` |
| 頁面底色 | `canvas` | `#F6F6F7` |
| 表面 | `paper` | `#FFFFFF` |
| 框線 | `line` | `#BCC1CA` |
| 主要行動 | `blue` | `#4387FF` |
| 主要行動 hover／連結 | `blue-deep` | `#2869DC` |
| 藍色淡底 | `blue-soft` | `#E9F0FF` |
| 萊姆亮點 | `lime` | `#DFFF6B` |
| 粉紅亮點 | `rose` | `#FFDDE3` |
| 黃色亮點 | `yellow` | `#FFF1A8` |
| 正常狀態 | `mint` | `#C9F2DF` |

禁止以任意相近色替代上述 token，也不要將顏色值散落在 TSX/JSX。

## 3. 字體、框線與圓角

- 字體：`Inter, "Noto Sans TC", "Microsoft JhengHei", Arial, sans-serif`。
- 所有中文字維持正常字距，不使用負字距。
- 大標題：字重 `850`、行高 `1.06` 至 `1.12`、無襯線。
- 一般內文：字重 `400` 至 `500`、行高約 `1.55` 至 `1.75`。
- 所有主要表面使用 `1.5px solid #BCC1CA`。高亮度螢幕上不可退回 `#E5E5E8` 等低對比框線。
- 控制項圓角：`9px` 至 `10px`。一般卡片：`14px` 至 `16px`。主題／大面板：`18px`。首頁預覽卡：`20px`。
- 陰影只能是輕微深灰陰影，用於浮動預覽與可點選卡片；不能用光暈或大面積陰影取代框線。

## 4. 版面骨架

### 公開頁面共通

1. 黑色細提示列只在「示意／預覽」環境使用，正式站不必保留。
2. 白底固定表頭：品牌在左、公開導覽在中或右、手機以單一選單圖示收合。
3. 內容寬度最大 `1160px`，桌機左右保留約 `4.5vw`，手機最少 `15px` 至 `18px`。
4. 內容表面以白色與明確框線區隔於 `canvas` 背景。
5. 任何頁面的麵包屑只連到真實可抵達的上層路徑；最後一層不可點。

### 首頁

順序不可任意置換：

1. 一句生活任務主張與搜尋入口。
2. 五張快速入口預覽卡。
3. 本月情境選讀位置的視覺預留。它是 T27 草案，未核准前不得寫死成正式資料功能。
4. 熱門情境。
5. 熱門優惠分類。
6. 正在發生的回饋。
7. 從手上的卡開始。
8. 攻略文章。

首頁主張是「先從今天想完成的事，找到適合的卡。」搜尋、情境、既有卡片是三種平行入口；不可把其中一種藏起來。

### 列表、詳情與文章

- 搜尋與分類頁：標題、說明、篩選、可掃讀的結果卡，避免把所有欄位塞進第一行。
- 優惠詳情：標題與狀態、亮點、取得方式、回饋限制、官方來源，維持資訊層級。
- 卡片詳情：麵包屑為「首頁 / 信用卡 / 卡片名稱」；發卡銀行是明確可點選的關聯入口，不是假麵包屑層級。
- 銀行頁：無銀行列表 route 時，麵包屑使用「首頁 / 銀行名稱」。
- 攻略文章：單欄可閱讀寬度，使用淡藍 callout，不以卡片堆疊切碎文章內容。

## 5. 元件規則

| 元件 | 必須遵守 | 禁止 |
| --- | --- | --- |
| 主要按鈕 | 亮藍底、白字、`9px` 圓角 | 膠囊形、漸層、雙主按鈕競爭 |
| 次要按鈕／篩選 | 白底、`1.5px` 框線、藍色 active | 無框線的灰字按鈕 |
| 情境／分類卡 | 白底或指定亮色底、明確框線、標籤＋標題＋短說明＋行動 | 純裝飾彩色卡、過長文案 |
| 優惠列 | 類別、標題、摘要、meta、右側回饋值 | 只丟一個高回饋數字 |
| 本月選讀 | 黑底文字區＋亮藍圖像區＋萊姆行動按鈕 | 漸層英雄區、無連結目標的宣傳卡 |
| 麵包屑 | 藍色可點祖先＋不可點最後頁 | 連向不存在的資訊層級 |

## 6. 動態規則

- 只允許首頁五張快速入口預覽卡使用 `preview-bob`：4 秒、緩慢、上下最多 `6px`、每張錯開延遲。
- Hover 可上移最多 `4px` 至 `8px`，不改變版面尺寸。
- 其他頁面不使用持續動畫。
- 必須支援 `prefers-reduced-motion: reduce`，完全停用持續動畫與平滑捲動。

## 7. 明確禁止事項

- 不使用漸層、發光球、模糊光斑、擬 3D 裝飾或 Hero SVG 插畫。
- 不使用大面積紫色、深藍灰、米色或咖啡色系取代 token。
- 不把每個區塊包成浮動卡，也不巢狀卡片。
- 不隨意增加圓角，尤其不要使用 `rounded-full` 作為一般按鈕或卡片。
- 不因增加欄位而重設色彩、字體、圓角、框線或內容順序。
- 不刪除搜尋、生活情境、手上卡片三種入口任一項。

## 8. 交付前檢查

- 桌機 `1440px`、平板 `768px`、手機 `390px` 均無溢出、文字遮擋或卡片變形。
- 高亮度螢幕下，所有主要卡片的 `1.5px` 框線仍可辨識。
- 每個按鈕與麵包屑都有正確目標，不存在無法抵達的中間頁。
- 所有新元件使用 token class，不散落自行決定的 hex、圓角與陰影。
- 新增內容後，首頁五張預覽卡、三種入口與 T27 視覺預留仍保留。
