# T01 測試腳本

版本：v1  
日期：2026-06-15  
任務：T01 Project Bootstrap

## 前置準備

1. 確認已在專案根目錄：`C:\Users\user\Documents\Credit card web project`
2. 若尚未安裝套件，執行：`npm install`
3. 啟動開發伺服器：`npm run dev`

## 本機網址

預設開啟：`http://localhost:3000`

## 測試帳號或資料

T01 尚未接上登入驗證與資料庫，不需要測試帳號或 seed data。

## 測試步驟

1. 開啟 `http://localhost:3000`
   - 預期結果：看到「信用卡優惠查詢網站」首頁骨架，並有「搜尋優惠」入口。
   - 預期結果：首頁不應出現「後台登入」入口或任何連到 `/admin/login` 的連結。
2. 開啟 `http://localhost:3000/search`
   - 預期結果：看到「搜尋優惠」頁、篩選條件區、關鍵字輸入框與尚未連接資料庫提示。
3. 開啟 `http://localhost:3000/admin/login`
   - 預期結果：看到「後台登入」頁，包含 Email、Password 欄位與登入按鈕。
4. 開啟 `http://localhost:3000/admin`
   - 預期結果：看到「後台儀表板」頁與銀行、信用卡、分類、優惠、網站設定等占位入口。
