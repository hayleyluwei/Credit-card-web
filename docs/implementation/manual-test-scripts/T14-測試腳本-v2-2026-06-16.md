# T14 測試腳本 v2 - 真實信用卡資料欄位檢查

版本：v2  
日期：2026-06-16  
目的：在 T14 驗收流程中，用真實信用卡資料檢查前台與後台欄位是否好理解、好維護。

## 前置條件

- 本機服務已啟動：`http://localhost:3000`
- 已執行 seed：`npm.cmd run db:seed`
- 後台帳號：`admin@example.com`
- 後台密碼：`.env` 的 `ADMIN_PASSWORD`，目前為 `replace-with-a-local-admin-password`

## 前台測試

### 1. 首頁

開啟：

http://localhost:3000/

預期：

- 不應看到「後台登入」入口。
- 精選優惠應可看到真實資料，例如 CUBE、DAWHO、HSBC 相關優惠。
- 優惠卡片若有關聯卡片與銀行，應顯示來源摘要。

### 2. 搜尋永豐

開啟：

http://localhost:3000/search?q=%E6%B0%B8%E8%B1%90

預期：

- 看到「永豐銀行」。
- 看到「DAWHO現金回饋信用卡」或 DAWHO 相關優惠。
- 不應看到多餘的「搜尋說明」區塊。

### 3. 搜尋 HSBC

開啟：

http://localhost:3000/search?q=HSBC

預期：

- 看到「滙豐銀行」。
- 看到 `HSBC Traveller's Infinite Card` 或 `HSBC TravelOne Signature Credit Card`。
- 點進優惠後，相關卡片區塊應帶出卡片與銀行名稱。

### 4. 永豐銀行頁

開啟：

http://localhost:3000/banks/sinopac

預期：

- 看到「永豐銀行」。
- 信用卡列表看到「DAWHO現金回饋信用卡」與卡面圖片區塊。
- 相關優惠應包含 DAWHO 高回饋、悠遊卡自動加值、新戶行動支付或大戶屋活動。

### 5. 滙豐銀行頁

開啟：

http://localhost:3000/banks/hsbc-taiwan

預期：

- 看到「滙豐銀行」。
- 看到 `HSBC Traveller's Infinite Card`。
- 看到 `HSBC TravelOne Signature Credit Card`。
- 卡片列表與優惠列表應能清楚看出兩張卡各自的關聯。

### 6. DAWHO 卡片頁

開啟：

http://localhost:3000/cards/dawho-cashback-card

預期：

- 看到「DAWHO現金回饋信用卡」。
- 看到銀行名稱「永豐銀行」。
- 相關優惠至少包含「DAWHO 國內外最高 6% 現金回饋」。
- 檢查 `conditions` 文字是否太長、是否需要未來拆欄位。

### 7. HSBC TravelOne 卡片頁

開啟：

http://localhost:3000/cards/hsbc-travelone-signature-card

預期：

- 看到 `HSBC TravelOne Signature Credit Card`。
- 看到銀行名稱「滙豐銀行」。
- 相關優惠可區分「消費點數」與「旅遊保險與機場權益」。

### 8. DAWHO 優惠頁

開啟：

http://localhost:3000/offers/dawho-high-cashback-2026

預期：

- 看到「DAWHO 國內外最高 6% 現金回饋」。
- 看到「永豐銀行」與「DAWHO現金回饋信用卡」。
- 看到官方來源連結。
- 檢查「回饋上限」「最低消費」「條件」是否足夠放真實資料。

### 9. CUBE 優惠頁

開啟：

http://localhost:3000/offers/cube-cashback-3

預期：

- 看到「國泰世華銀行」與「CUBE 卡」。
- 也看到多卡關聯測試用的「台新銀行」與「FlyGo 卡」。
- 相關卡片區塊應顯示卡面圖片區塊與銀行名稱。

### 9-1. CUBE 餐飲優惠頁可操作性

開啟：

http://localhost:3000/offers/cube-dining-2026

預期：

- 頁面區塊應有「怎麼拿到優惠」「回饋與限制」「注意事項」。
- 不應只看到 `points` 這種資料庫代碼，應顯示「點數回饋」。
- 應看得到這段核心規則：每週四持 CUBE 信用卡國內餐廳消費單筆滿 NT$2,000，可獲加碼 5% 優惠券，每張優惠券回饋上限 100 點小樹點。
- 應看得到「每月餐廳消費累積滿 NT$20,000」與「不是所有餐廳都適用」這類限制。
- 看完後應能回答：哪一天刷、用哪張卡、在哪裡消費、單筆要多少、拿到什麼、上限是多少。

### 9-2. DAWHO 大戶屋優惠頁可操作性

開啟：

http://localhost:3000/offers/dawho-otoya-10-percent-off-2026

預期：

- 頁面區塊應有「怎麼拿到優惠」「回饋與限制」「注意事項」。
- 應看得到「活動期間：2026/5/15-2026/7/14」。
- 應看得到「至大戶屋餐廳點『永豐DAWHO幣倍套餐』」。
- 應看得到「結帳出示永豐DAWHO信用卡/幣倍卡」。
- 應看得到「專屬套餐優惠價$460元/份」「原價$510」「另須支付原價之10%服務費」。
- 應看得到「不得與其他店內優惠併用」。
- 應看得到套餐內容：滑蛋豬排鍋定食 / 野菜豬肉鍋定食 / 炸腰內肉定食三選一，加茶碗蒸、紅豆湯圓與紅茶。
- 看完後應能回答：活動期間、去哪家店、點哪個套餐、結帳要出示什麼、實付優惠價、額外服務費、是否可併用。

## 後台測試

### 10. 後台登入

開啟：

http://localhost:3000/admin/login

操作：

- Email 輸入 `admin@example.com`
- Password 輸入 `replace-with-a-local-admin-password`

預期：

- 成功登入後可進入後台首頁。

### 11. 信用卡管理

開啟：

http://localhost:3000/admin/cards

預期：

- 非後台首頁頁面上方應看到「回後台首頁」。
- 列表可看到 CUBE、DAWHO、HSBC Traveller、HSBC TravelOne。
- 「卡面圖片 URL」欄位說明應提到會影響信用卡詳情頁、銀行詳情頁、優惠詳情頁。

### 12. 優惠管理

開啟：

http://localhost:3000/admin/offers

預期：

- 非後台首頁頁面上方應看到「回後台首頁」。
- 可找到 DAWHO、HSBC、CUBE 相關優惠。
- 點進編輯頁後，檢查長條件文字是否容易維護。

### 13. 銀行管理

開啟：

http://localhost:3000/admin/banks

預期：

- 可看到「國泰世華銀行」「永豐銀行」「滙豐銀行」。
- 前台銀行頁應能對應到這些資料。

## 若結果不符請回報

- 發生問題的完整網址。
- 頁面截圖。
- 你覺得不好理解的欄位名稱或區塊名稱。
- 如果是資料太長，請指出哪個欄位最難讀：`summary`、`description`、`rewardCap`、`minSpend`、`conditions`、`tags`。

## Pass / Fail Checklist

- [ ] 首頁沒有後台登入入口。
- [ ] `/search?q=永豐` 可找到永豐與 DAWHO。
- [ ] `/search?q=HSBC` 可找到滙豐與兩張 HSBC 卡。
- [ ] 銀行頁可看到信用卡列表與卡面圖片區塊。
- [ ] 卡片頁可看到相關優惠。
- [ ] 優惠頁可看到適用卡片與銀行名稱。
- [ ] 後台非首頁頁面有回後台首頁入口。
- [ ] 後台卡片圖片欄位說明能理解它會出現在前台哪裡。
