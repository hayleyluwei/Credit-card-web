# T14 測試腳本 v5 - 首頁依信用卡查優惠入口

版本：v5  
日期：2026-06-22  
目的：驗證首頁新增「依信用卡查優惠」入口後，使用者可以從手上的信用卡進入單張信用卡優惠頁。

## 前置條件

本機服務：

http://localhost:3000/

## 1. 首頁應看到依信用卡查優惠區塊

開啟：

http://localhost:3000/

預期：

- 首頁不應出現後台登入入口。
- 應看到「依信用卡查優惠」。
- 應看到「選你手上的信用卡」。
- 應看到多張信用卡卡片，例如：
  - 國泰世華 CUBE 卡
  - DAWHO現金回饋信用卡
  - HSBC TravelOne Signature Credit Card
- 每張信用卡應顯示：
  - 卡面圖片或替代字母
  - 銀行名稱
  - 信用卡名稱
  - 簡短說明
  - 目前公開優惠筆數
  - 「查看這張卡」

## 2. 點信用卡應進入單張信用卡頁

從首頁點任一張信用卡，例如：

http://localhost:3000/cards/dawho-cashback-card

預期：

- 可正常開啟信用卡詳情頁。
- 頁面應顯示信用卡名稱與銀行名稱。
- 頁面應有「相關優惠」區塊。
- 相關優惠應只呈現與該信用卡關聯的公開優惠。

## 3. 可從首頁用關鍵字搜尋優惠

開啟：

http://localhost:3000/

操作：

- 在「依信用卡查優惠」區塊右上點「用關鍵字搜尋優惠」。

預期：

- 應前往：

http://localhost:3000/search

- 搜尋頁可以正常開啟。

## 4. RWD 快速檢查

請用瀏覽器縮窄視窗或手機尺寸檢查：

http://localhost:3000/

預期：

- 信用卡卡片應上下排列。
- 卡名、銀行名稱、優惠筆數、查看這張卡不應互相重疊。
- 卡面圖片不應擠壓到文字。

## 快速自動檢查

可執行：

```powershell
npm.cmd run smoke:homepage-card-entry
```

預期：

- 顯示 `Homepage card entry smoke test passed.`

## Pass / Fail Checklist

- [ ] 首頁有「依信用卡查優惠」區塊。
- [ ] 首頁顯示信用卡卡片與銀行名稱。
- [ ] 信用卡卡片可連到 `/cards/[slug]`。
- [ ] 單張信用卡頁有「相關優惠」。
- [ ] 首頁仍沒有後台登入入口。
- [ ] 手機寬度下版面沒有重疊。
