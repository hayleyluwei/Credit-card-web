## 問題排查

### Seed 失敗：ProtocolError

**症狀：** seed.mjs 執行時出現 `ProtocolError`

**解決方案：**
1. 確保 `DATABASE_URL` 在 `.env` 中正確設定
2. 刪除 `prisma/dev.db` 並重新執行 `npm run db:push`
3. 再次執行 `npm run db:seed`

### 密碼未加密

**症狀：** AdminUser 的 `passwordHash` 是純文字

**解決方案：**
1. 確保 `bcryptjs` 已安裝：`npm install bcryptjs`
2. 刪除 `prisma/dev.db` 並重新 seed

### Smoke 測試失敗

**症狀：** `npm run smoke:t03` 報告缺少資料

**解決方案：**
1. 查看具體的失敗訊息
2. 確認 seed.mjs 中的資料定義是否與 smoke 測試的期望相符
3. 重新執行 seed 並檢查輸出
