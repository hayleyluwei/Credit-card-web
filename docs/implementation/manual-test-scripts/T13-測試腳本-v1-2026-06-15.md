## 前置準備

1. 確認已執行 `npm run db:seed`
2. 啟動本機服務：`npm run dev`
3. 使用管理員帳號登入 `/admin/login`

## 測試頁面

- `http://localhost:3000/`
- `http://localhost:3000/search`
- `http://localhost:3000/banks/{slug}`
- `http://localhost:3000/cards/{slug}`
- `http://localhost:3000/admin`
- `http://localhost:3000/admin/offers`
- `http://localhost:3000/admin/offers/new`

## 測試步驟

1. Mobile viewport
   - 使用瀏覽器 DevTools 切到 390px 寬度
   - 首頁搜尋、分類入口、優惠卡片不可互相重疊
   - `/search` 搜尋欄與結果卡片可正常閱讀
   - bank/card detail 的 logo 或卡片圖片應維持固定區塊，不造成 layout shift
   - `/admin` 導航、統計卡、提醒與快速操作可縱向閱讀
   - `/admin/offers` 篩選表單、列表項目與編輯按鈕不可溢出
   - `/admin/offers/new` 表單欄位應單欄排列，發布按鈕可點擊

2. Tablet viewport
   - 使用 768px 寬度
   - public listing 應以可掃描的欄位排列
   - admin 表單應在空間足夠時轉為雙欄，文字不可擠壓

3. Desktop viewport
   - 使用 1280px 以上寬度
   - public detail 主要內容與側欄應並排
   - admin dashboard 與 offer editor 應保持可掃描，不應出現過寬文字行
