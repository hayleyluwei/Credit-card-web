# T09 測試腳本

版本：v1  
日期：2026-06-15  
任務：T09 Admin Auth

## 前置準備

1. 確認已在專案根目錄：`C:\Users\user\Documents\Credit card web project`
2. 確認已執行：`npm run db:seed`
3. 確認 `.env` 包含：
   - `NEXTAUTH_URL="http://localhost:3000"`
   - `NEXTAUTH_SECRET`
   - `ADMIN_EMAIL`
   - `ADMIN_PASSWORD`
4. 啟動開發伺服器：`npm run dev`

## 本機網址

- 後台登入：`http://localhost:3000/admin/login`
- 後台首頁：`http://localhost:3000/admin`

## 測試帳號

- Email：使用 `.env` 的 `ADMIN_EMAIL`
- Password：使用 `.env` 的 `ADMIN_PASSWORD`

## 測試步驟

1. 未登入時開啟 `http://localhost:3000/admin`
   - 預期結果：自動導向 `/admin/login`。
2. 在登入頁輸入錯誤密碼。
   - 預期結果：登入失敗，仍留在登入頁，顯示錯誤訊息。
3. 在登入頁輸入正確管理者帳密。
   - 預期結果：登入成功並進入 `/admin`。
4. 在 `/admin` 點擊「登出」。
   - 預期結果：登出後回到 `/admin/login`。
5. 登出後再次開啟 `/admin`。
   - 預期結果：仍會被導向 `/admin/login`。
