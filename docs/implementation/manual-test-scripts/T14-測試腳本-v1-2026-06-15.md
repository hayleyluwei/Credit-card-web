# T14 測試腳本

版本：v1  
日期：2026-06-15  
任務：T14 MVP Acceptance Pass

## 前置準備

1. 確認 `.env` 已設定 `DATABASE_URL`、`NEXTAUTH_URL`、`NEXTAUTH_SECRET`、`ADMIN_EMAIL`、`ADMIN_PASSWORD`
2. 執行 `npm run db:seed`
3. 啟動本機服務：`npm run dev`
4. 使用管理員帳號登入 `http://localhost:3000/admin/login`

## 手動驗收步驟

1. UX follow-up checks
   - 開啟 `http://localhost:3000/admin/cards`，確認頁面上方有「回後台首頁」
   - 開啟 `http://localhost:3000/admin/offers/new`，確認頁面上方有「回後台首頁」
   - 開啟 `http://localhost:3000/admin/settings`，確認頁面上方有「回後台首頁」
   - 在 `http://localhost:3000/admin/cards` 確認「卡面圖片 URL」說明有提到信用卡詳情頁、銀行詳情頁、優惠詳情頁
   - 開啟 `http://localhost:3000/search?q=永豐`，確認搜尋結果包含「永豐銀行」相關優惠
   - 開啟 `http://localhost:3000/search`，確認沒有多餘的「搜尋說明」區塊
   - 開啟 `http://localhost:3000/offers/cube-cashback-3`，確認適用信用卡區塊顯示「國泰世華銀行」、「台新銀行」、信用卡名稱與卡面圖片
   - 開啟 `http://localhost:3000/banks/cathay`，確認信用卡列表顯示卡面圖片或 placeholder

2. Public frontend
   - 開啟 `http://localhost:3000/`
   - 確認首頁沒有後台登入入口
   - 使用首頁搜尋進入 `http://localhost:3000/search`
   - 開啟一個分類頁、一個銀行頁、一個信用卡頁、一個優惠詳情頁
     - 分類頁範例：`http://localhost:3000/categories/cashback`
     - 銀行頁範例：`http://localhost:3000/banks/cathay`
     - 信用卡頁範例：`http://localhost:3000/cards/cube-card`
     - 優惠詳情頁範例：`http://localhost:3000/offers/cube-cashback-3`
   - 確認公開頁只顯示已發布優惠

3. Search and sorting
   - 搜尋優惠標題、信用卡名稱、銀行名稱、分類名稱與 tag
   - 確認搜尋結果使用一致的 offer card 樣式
   - 確認搜尋結果可看出銀行/信用卡來源
   - 確認空結果狀態可理解

4. SEO
   - 開啟 `http://localhost:3000/sitemap.xml`
   - 開啟 `http://localhost:3000/robots.txt`
   - 檢查公開頁 HTML 有 canonical 與 JSON-LD
   - 有 FAQ JSON 的頁面才應輸出 FAQPage JSON-LD

5. Admin auth
   - 登出後開 `http://localhost:3000/admin`
   - 確認會被導向登入
   - 使用正確管理員帳號登入
   - 使用錯誤密碼不應登入

6. Admin CRUD
   - `http://localhost:3000/admin/settings` 可儲存設定
   - `http://localhost:3000/admin/banks` 可新增、編輯、搜尋、啟用/停用
   - `http://localhost:3000/admin/cards` 可新增、編輯、搜尋、啟用/停用，並能理解卡面圖片 URL 的前台用途
   - `http://localhost:3000/admin/categories` 可新增、編輯、啟用/停用，FAQ JSON 驗證有效

7. Offer editor
   - `http://localhost:3000/admin/offers` 可搜尋、依發布狀態與分類篩選
   - `http://localhost:3000/admin/offers/new` 可儲存不完整草稿
   - 儲存並發布會要求必要欄位與至少一張關聯信用卡
   - 編輯已發布優惠後，公開頁會反映內容更新
   - 取消發布後，公開頁不應顯示該優惠

8. RWD
   - 在 390px、768px、1280px viewport 檢查 public/admin 主要頁面
   - 確認文字、按鈕、圖片、表單與卡片沒有重疊或不可用
