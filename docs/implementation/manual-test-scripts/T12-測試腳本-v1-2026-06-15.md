# T12 測試腳本

版本：v1  
日期：2026-06-15  
任務：T12 Admin Offer Editor

## 前置準備

1. 確認已執行 `npm run db:seed`
2. 啟動本機服務：`npm run dev`
3. 使用管理員帳號登入 `/admin/login`

## 測試頁面

- `http://localhost:3000/admin/offers`
- `http://localhost:3000/admin/offers/new`
- `http://localhost:3000/admin/offers/{id}`

## 測試步驟

1. 優惠列表
   - 開啟 `/admin/offers`
   - 確認可看到「優惠管理」、「新增優惠」、「搜尋優惠」、「發布狀態」、「分類篩選」
   - 使用關鍵字、發布狀態、分類篩選，確認列表會更新
   - 已發布優惠應可點「查看公開頁」

2. 新增草稿
   - 開啟 `/admin/offers/new`
   - 填寫優惠標題、分類與部分內容
   - 不選信用卡或不填來源網址時，點「儲存草稿」應仍可儲存
   - 儲存後應進入該優惠的編輯頁

3. 發布驗證
   - 在新增或編輯頁確認可看到「發布驗證」
   - 若要「儲存並發布」，需填入標題、slug、分類、摘要預覽或可 fallback 的摘要、來源網址、回饋類型或回饋內容，並至少選一張信用卡
   - 缺少必要欄位時不應發布成功

4. 編輯優惠
   - 開啟既有優惠編輯頁
   - 確認可看到「編輯優惠」、「優惠標題」、「來源網址」、「最後確認日期」、「FAQ JSON」、「取消發布」
   - 修改摘要、回饋內容、日期、SEO 欄位、FAQ JSON 後儲存
   - 回到公開優惠頁，確認已發布優惠的內容會反映更新

5. 取消發布
   - 在已發布優惠編輯頁點「取消發布」
   - 回到 `/admin/offers` 確認狀態變為草稿
   - 公開優惠頁不應再能開啟該草稿優惠
