## 前置準備

1. 確認已執行：`npm run db:seed`
2. 啟動開發伺服器：`npm run dev`
3. 使用 T09 管理者帳號登入。

## 本機網址

- `http://localhost:3000/admin`

## 測試步驟

1. 開啟 `/admin`
   - 預期結果：若未登入，會導向 `/admin/login`。
2. 登入後開啟 `/admin`
   - 預期結果：看到「後台工作台」。
3. 檢查導覽列
   - 預期結果：看到「優惠管理」、「銀行管理」、「信用卡管理」、「分類管理」、「網站設定」。
4. 檢查統計卡
   - 預期結果：看到「已發布優惠」、「草稿優惠」、「過期優惠」、「信用卡數」、「銀行數」。
5. 檢查維護提醒
   - 預期結果：看到「即將到期」、「缺少來源連結」、「缺少圖片」、「待重新確認」。
6. 檢查快速操作
   - 預期結果：看到「新增優惠」、「新增信用卡」、「管理分類」。
