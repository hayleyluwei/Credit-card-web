# T05 Manual Test Script - Public Frontend Foundation

日期：2026-06-15  
版本：v1  
任務：Public Frontend Foundation

## 前置條件

- 已完成 T04（Domain Rules And Validation）
- 已完成 T03 種子資料並執行 `npm run db:seed`
- 本地開發環境可執行 `npm run dev`

## 測試步驟

### 步驟 1：啟動本地開發伺服器

```bash
npm run dev
```

開啟瀏覽器並前往：
- `http://localhost:3000`

**預期結果：**
- 首頁能正常載入
- 有分類入口、精選優惠與最新優惠區塊
- 能夠點選「瀏覽分類」或「搜尋優惠」連結

### 步驟 2：驗證首頁內容

首頁應包含：
- `分類入口` 區塊
- `精選優惠` 區塊
- `最新優惠` 區塊

檢查：
- 精選優惠區顯示已發布且可見的優惠
- 最新優惠區顯示已發布優惠
- 每張優惠卡片有狀態標籤、優惠標題、摘要、回饋與結束日期

### 步驟 3：驗證分類頁列表

前往：
- `http://localhost:3000/categories`

**預期結果：**
- 頁面列出所有 `isActive = true` 的分類
- 每個分類卡有分類名稱、優惠數量與連結
- 可點選進入分類詳情頁

### 步驟 4：驗證分類詳情頁

點選其中一個分類，例如 `現金回饋`，前往：
- `/categories/[slug]`

**預期結果：**
- 分類名稱、說明、分類資訊區塊顯示正確
- 已發布優惠列表正確顯示於主區塊
- 若分類有 FAQ，側邊欄顯示 FAQ 區塊
- 優惠卡片顯示過期標記（若該優惠已過期）

### 步驟 5：驗證路由與導覽

確認以下連結可正常跳轉：
- 首頁 → 搜尋頁面 `/search`
- 首頁 → 分類頁 `/categories`
- 分類列表 → 分類詳情
- 分類詳情反回首頁或分類列表

### 步驟 6：檢查 SEO metadata

在瀏覽器開發者工具中查看首頁與分類頁的 `<title>` 與 `<meta name="description">` 是否正確。

## 問題排查

### 首頁沒有優惠

- 確認 `npm run db:seed` 已經執行
- 確認資料庫中的 `Offer.isPublished` 有啟用項目
- 確認 `SiteSetting.showExpiredOffers` 是否為 false，過期優惠將被過濾

### 分類頁顯示 404

- 確認 slug 是否正確對應 `Category.slug`
- 確認該分類 `isActive = true`
- 確認分類的 `offers` 中至少有 `isPublished = true` 的優惠

### FAQ 無法顯示

- 確認 `Category.faqJson` 是有效 JSON
- 確認 FAQ JSON 格式為陣列，每個項目包含 `question` 與 `answer`
