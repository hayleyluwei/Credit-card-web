# T02 測試腳本

版本：v1  
日期：2026-06-15  
任務：T02 Prisma Database

## 前置準備

1. 確認已在專案根目錄：`C:\Users\user\Documents\Credit card web project`
2. 確認已安裝 Node 套件：`npm install`
3. 確認 `.env` 存在，且包含：`DATABASE_URL="file:./dev.db"`

## 本機網址

T02 主要測試資料庫與 Prisma，不需要開瀏覽器頁面。若要確認 app 仍可啟動，可開：`http://localhost:3000`

## 測試帳號或資料

T02 尚未建立 seed data，因此資料表可以是空的。T03 會加入管理者帳號與展示資料。

## 測試步驟

1. 執行 `npm run prisma:validate`
   - 預期結果：看到 schema valid 訊息。
2. 執行 `npm run prisma:generate`
   - 預期結果：看到 Prisma Client generated 訊息。
3. 執行 `npm run db:push`
   - 預期結果：看到 database is now in sync 訊息。
4. 執行 `npm run smoke:t02`
   - 預期結果：看到 `T02 Prisma smoke test passed.`

## 異常回報

若 Prisma 指令失敗，請截圖或貼上：

- 執行的指令
- 完整錯誤訊息
- `prisma/schema.prisma` 是否存在
- `prisma/dev.db` 是否存在
