# T11 測試腳本

版本：v1  
日期：2026-06-15  
任務：T11 Admin Basic CRUD

## 前置準備

1. 確認已執行 `npm run db:seed`
2. 啟動本機服務：`npm run dev`
3. 使用 T09 建立的管理員帳號登入 `/admin/login`

## 測試頁面

- `http://localhost:3000/admin/settings`
- `http://localhost:3000/admin/banks`
- `http://localhost:3000/admin/cards`
- `http://localhost:3000/admin/categories`

## 測試步驟

1. 網站設定
   - 開啟 `/admin/settings`
   - 確認可看到「網站設定」、「站台名稱」、「預設 SEO 標題」、「儲存設定」
   - 修改站台名稱或 SEO 欄位後儲存，重新整理頁面確認值仍存在

2. 銀行管理
   - 開啟 `/admin/banks`
   - 確認可看到「銀行管理」、「新增銀行」、「搜尋銀行」、「啟用」、「停用」
   - 新增一筆測試銀行，填入唯一 slug
   - 進入既有銀行編輯頁，確認可看到「編輯銀行」、「Slug」、「SEO 標題」、「儲存銀行」
   - 切換啟用/停用狀態後，確認列表狀態更新

3. 信用卡管理
   - 開啟 `/admin/cards`
   - 確認可看到「信用卡管理」、「新增信用卡」、「搜尋信用卡」、「所屬銀行」
   - 新增一張測試信用卡並選擇所屬銀行
   - 進入既有信用卡編輯頁，確認可看到「編輯信用卡」、「所屬銀行」、「卡片圖片 URL」、「儲存信用卡」
   - 切換啟用/停用狀態後，確認列表狀態更新

4. 分類管理
   - 開啟 `/admin/categories`
   - 確認可看到「分類管理」、「新增分類」、「FAQ JSON」、「排序」
   - 新增一個測試分類，FAQ JSON 可留空
   - 輸入格式錯誤的 FAQ JSON 時，應由系統阻擋
   - 進入既有分類編輯頁，確認可看到「編輯分類」、「FAQ JSON」、「排序」、「儲存分類」

5. 搜尋與公開頁反映
   - 在銀行與信用卡列表使用搜尋欄，確認列表會依關鍵字縮小
   - 修改銀行、信用卡或分類的名稱/slug/啟用狀態後，到相關公開頁確認資料反映
   - SEO 欄位留空時，公開頁仍應能使用 fallback metadata，不應出錯
