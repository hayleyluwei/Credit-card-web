## 常見問題排查

### Slug 包含 CJK 字符

**症狀：** generateSlug 輸出包含非英文字符

**原因：** 正規表達式 `[^\w\s-]` 在某些 Unicode 環境中可能包括 CJK 字符

**驗證：** slug 不應包含中文、日文或韓文字符

### 驗證失敗在 publishValidation

**症狀：** 有效的優惠仍然驗證失敗

**解決：**
1. 確認所有必填欄位都有值（title, slug, categoryId, summaryPreview, sourceUrl）
2. 確認至少有一個 reward（rewardType 或 rewardValue）
3. 確認至少有一張相關的 card（OfferCard 關聯）

### 排序順序錯誤

**症狀：** sortOffers 返回的順序不符合預期

**驗證：**
1. Check `isFeatured` values (true should come first)
2. If featured is the same, check `recommendScore` (higher first)
3. If score is the same, check `sortOrder` (lower first)
4. If order is the same, check `updatedAt` (newer first)
