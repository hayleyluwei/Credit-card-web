# T23 後台顏色欄位「儲存＋前台反映」完整迴圈測試腳本

版本：v1
建立日期：2026-07-30（Asia/Taipei）
用途：驗證 `AdminCardForm` 的 5 個卡面配色欄位，從後台儲存到前台 SVG 卡面示意圖正確反映的完整迴圈。此前僅確認欄位存在，未完整跑過「改值 → 儲存 → 前台核對 → 改回」全流程。

## 前置說明

- 本測試需要後台管理員登入。依專案安全規則，AI 不會、也不應代為輸入管理員密碼，此腳本由**使用者本人登入操作**；AI 可在使用者完成儲存步驟後，改用瀏覽器唯讀方式核對前台渲染結果（不需登入）。
- 測試對象欄位（皆在 `/admin/cards/[id]` 編輯頁的「卡面示意圖配色」區塊）：
  - `卡面底色（起始）` → `cardBgColorFrom`
  - `卡面底色（結束）` → `cardBgColorTo`
  - `卡片名稱文字顏色` → `cardTextColor`
  - `晶片顏色（起始）` → `cardChipColorFrom`
  - `晶片顏色（結束）` → `cardChipColorTo`
- 建議挑一張**目前已有官網真實配色、且沒有填「卡面圖片 URL」**的卡片（例如 momo卡），方便測試後比對是否正確還原。

## 測試步驟

1. 登入 `/admin`，進入該卡片編輯頁 `/admin/cards/[id]`。
2. 開始前，先記下 5 個顏色欄位的**目前值**（截圖或抄下 hex 值），供步驟 6 還原用。
3. 把 5 個欄位改成明顯不同、容易辨識的測試色，例如：
   - `cardBgColorFrom` = `#FF0000`
   - `cardBgColorTo` = `#00FF00`
   - `cardTextColor` = `#0000FF`
   - `cardChipColorFrom` = `#FFFF00`
   - `cardChipColorTo` = `#FF00FF`
4. 點擊「儲存草稿 / 更新」，確認畫面出現綠色「儲存成功」訊息（無錯誤）。
5. 開啟該卡片對應的前台頁面（卡片詳情頁，或任一顯示該卡示意圖的優惠頁／首頁區塊），確認 SVG 卡面示意圖的漸層底色、文字顏色、晶片顏色皆已變成步驟 3 填入的測試色。
   - 核對方式：右鍵檢視原始碼或用瀏覽器開發工具找 SVG `<stop>` / `fill` 屬性的 hex 值，逐一比對。
6. 回到編輯頁，把 5 個欄位改回步驟 2 記下的原始值，再次儲存。
7. 重新整理前台頁面，確認卡面示意圖已恢復原本配色（與其他同樣走真實配色的卡片視覺一致，無殘留測試色）。
8. 記錄結果：
   - 通過 / 失敗 / 無法確認（三選一，不得逕自宣稱完成）
   - 若失敗，記錄哪個欄位沒有正確反映、實際看到的顏色
   - 附截圖或核對用的 SVG hex 值截圖

## 完成定義

- 5 個欄位皆確認「填值可儲存、前台正確反映、清空或改回可還原」，且原卡片資料已還原為官網真實配色，未留下測試色。
- 若使用者已完成步驟 1-7，可請 AI 協助以瀏覽器唯讀核對步驟 5、7 的前台渲染結果（不涉及登入）。
