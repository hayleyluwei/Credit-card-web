## 已知影響與未解事項

1. **後台外觀會偏移**：`ink`／`paper`／`line` 是共用 token，值改變後後台跟著變
   （`paper` 由淺灰翻轉為純白、框線變深變粗、字體改變）。**未修改任何後台程式碼**；
   已保留 `brand.*` 與 `shadow-soft` 確保不會靜默破版。使用者已知悉並接受。
2. **首頁失去「每筆都附官方來源」訊息**：隨舊副標移除，目前只在頁尾。
3. **聯絡信箱防爬的限度**：base64＋掛載後解出，擋得掉不執行 JS 的爬蟲，
   擋不掉會執行 JS 者。要真正杜絕需改聯絡表單（需寄信服務＋機密＋防濫用），屬獨立功能。
4. **既有缺陷未修**：優惠詳情頁 `rewardType=other` 顯示英文 `other`
   （`formatRewardType` 缺對照）。2026-08-04 即記錄在案，修正屬行為變更非視覺套用。
5. **長期風險（非本輪產生）**：本機 `.env` 的 `DATABASE_URL` 直接指向正式站 Neon，
   沒有獨立開發資料庫。本機 dev server、任何寫入腳本都是直接動正式站。
6. **管理員密碼**：使用者於本輪表示忘記，已建立 `scripts/reset-admin-password.mjs`
   （預設 dry-run，需 `--confirm`；密碼在執行者本機產生、只印一次）。
   **使用者尚未執行**，下次要用後台時需自行重設。
