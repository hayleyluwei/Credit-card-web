# T19 卡片結構化欄位與蒐集規格擴充

建立日期：2026-07-17（Asia/Taipei）
任務卡版本：v1
核准狀態：已核准
問題類型：功能／架構／內容文件

## 背景

2026-07-17 與使用者討論 KOL 式信用卡內容（以寶可孟 Visa 無限卡整理文為例）後確認兩個缺口：

1. `Card` 模型缺少呈現「一張卡值不值得辦」的結構化欄位：年費、免年費條件、卡片等級（無限卡／御璽卡等）、發卡組織（Visa／Mastercard／JCB）、優點與注意事項。目前卡片詳情頁只有銀行、客群與一段說明，內容過於精簡。
2. 使用者的核心目標之一是網站內容能被 AI 引用。AI 查詢多為情境式（繳稅、學費、水電費刷哪張卡），現行資料蒐集規格的標籤清單（規格書 4.3 節）沒有涵蓋這類消費情境標籤。

資料整理人員的試算表尚未交付，趁交付前擴充規格與模板，可讓整理人員一次收齊，避免上線後補收資料與二次匯入。

相關文件：

- 上層計畫：`docs/superpowers/plans/2026-07-08-FIRST_RELEASE_第一版上線實作計畫.md`
- 蒐集規格書：`docs/data-collection/DATA_COLLECTION_SPEC_信用卡優惠資料蒐集與分類規格書-v1-2026-07-08.md`
- 資料模板：`docs/data-collection/信用卡優惠資料整理模板-v1-2026-07-08.xlsx`
- 資料模型：`prisma/schema.prisma`（`Card` 模型）

## 已確認決策

- 使用者 2026-07-17 確認方向：網站要兼具「信用卡分類」與「詳細的信用卡使用說明（優點／注意事項）」，且內容要能被 AI 引用；並指示起草本任務卡。
- KOL 內容不得直接抄錄：只參考其資訊架構與選題，所有數字與條件回到官方來源查證後改寫（延續規格書 3.1 來源優先順序與 6.8 術語白話原則）。
- T16–T18 第一版上線仍為主線（2026-07-08 拍板事項不變）。

## 目標

卡片詳情頁能呈現年費、免年費條件、卡片等級、發卡組織與優點／注意事項；優惠資料具備消費情境標籤；資料蒐集規格與模板一次收齊上述欄位，讓整理人員交付一輪即可。

## Scope v1

- `prisma/schema.prisma` 的 `Card` 模型新增可選欄位：
  - `annualFee`（年費說明，字串）
  - `annualFeeWaiver`（免年費條件，字串）
  - `cardLevel`（卡片等級，字串）
  - `cardNetwork`（發卡組織，字串）
  - `prosJson`（優點清單，JSON 字串陣列）
  - `consJson`（注意事項清單，JSON 字串陣列）
- 建立對應 Prisma migration，只作用於本機 SQLite；執行前備份 `prisma/dev.db`。
- `src/app/cards/[slug]/page.tsx` 呈現新欄位（有值才顯示，無值不顯示空區塊）。
- 後台卡片編輯表單與對應 server actions 支援新欄位的讀寫與驗證。
- 蒐集規格書升版 v2：
  - 5.2 `cards` 工作表新增欄位：年費、免年費條件、卡片等級、發卡組織、優點（分行條列）、注意事項（分行條列），並定義填寫規則與範例。
  - 4.3 標籤清單新增固定的消費情境標籤草案：`繳稅`、`學費`、`水電瓦斯`、`保費`、`加油`、`外送`、`超市量販`、`旅遊訂房`（清單於核准時由使用者拍板增刪）。
- xlsx 模板同步升版（新增 cards 欄位；offers 標籤說明更新），既有 DAWHO 資料列不刪除。
- 若屆時 `scripts/import-offer-data.mjs`（T16）已存在，同步支援新欄位；若尚未建立，將欄位對應需求記入 T16 任務卡的相依備註。
- 建立 T19 Summary，更新 `docs/implementation/01-ACTIVE_TASK_INDEX_目前任務索引.md` 與 `CURRENT_STATE_目前專案狀態.md`。

- 自動驗證：
  - `npx prisma migrate dev`（或等效指令）在備份完成後執行成功；指令目前為 `unclassified`，執行前依驗證政策取得使用者同意或由使用者執行。
  - lint 與 build 通過（同上，分類未核准前由使用者執行或逐次同意）。
- 人工驗收：
  - 使用者抽點任一張填有新欄位的卡片詳情頁，確認年費、等級、優缺點正確顯示；未填欄位的卡片頁不出現空區塊。
  - 使用者審閱規格書 v2 差異與情境標籤清單。
- 完成定義：migration 成功、卡片頁與後台表單驗收通過、規格書 v2 與模板經使用者確認、Summary 完成。

- 備份檔不進 Git（`.gitignore` 已涵蓋）。
